# بستهٔ انتقال استک دوهاب برای سرور جدید

این پوشه مال **شما** است (داکیومنت + پرامپت + اسکریپت). سکرت و لیست کاربر این استک داخلش نیست.

| فایل | برای کی |
|---|---|
| `CURSOR-PROMPT.md` | اول بلوک **OPERATOR VALUES** را پر کن، بعد کپی → دوست → Cursor |
| `IMPLEMENTATION-GUIDE.md` | داکیومنت خودتان؛ مراحل با جزئیات |
| `NODE-DISABLED.md` | چرا نود پنل خاموش است و کی می‌شود روشنش کرد |
| `SCRIPTS-INSTALL.md` | نصب vpn-path و sync/stats (بخش‌های ضریب/دیده‌بان/مانیتور برای دوست لازم نیست) |
| `vpn-infra-portable-scripts.tar.gz` | بریزید روی سیستم شخصی، بعد بدهید به Cursor دوست |

**برای دوست نده / در پرامپت نخواه:** ضریب Instagram/porn، sni-watch، monitor — ابزار شخصی خودتان.

چاپ PDF: فایل `IMPLEMENTATION-GUIDE.html` را در Chrome/Edge باز کنید → Print → Save as PDF (wkhtmltopdf حروف فارسی را جدا می‌کند؛ از آن استفاده نکنید).

روی سیستم شخصی کل پوشه `docs/friend-deploy` به‌علاوه tar اسکریپت‌ها را کپی کنید.
